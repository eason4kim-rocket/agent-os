# Conformance：行为契约清单

> 协议的价值在于"多实现一个行为"。本清单定义【任何实现】都必须满足的可观测行为。
> 每条案例标注：协议依据、验证方式、覆盖状态（Python / Rust）。
> 新增行为契约 = 先改本清单 + 加两端测试 + 实现对齐，三处同一 PR。
